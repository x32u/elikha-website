# e-Likha frontend workflow

For UI and frontend implementation in this repository:

- Use the installed `frontend-design` skill to guide visual design decisions.
- Use the installed `web-design-guidelines` skill to review accessibility, responsiveness, performance, and UX before completion.
- Use the installed `motion` React package for purposeful interface animation when it improves clarity or feedback. Keep animations restrained and support reduced-motion preferences.

Preserve the established e-Likha visual identity and verify layouts at both desktop and mobile sizes.
